# Nura Wallet

A self-custodial Ethereum wallet for Windows and Android. Your keys never leave
the device: the recovery phrase is encrypted with AES-GCM before it is stored,
and the passphrase that unlocks it is hashed with Argon2id. Send and receive
native coins and ERC-20 tokens, switch between networks, and browse dApps from
inside the app.
